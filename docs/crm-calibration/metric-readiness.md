## 数据接入施工边界

1. 通过现有认证指标服务扩展受控聚合合同；模型继续只传时间、渠道和低价条件，不获得 SQL 或数据库路径。
2. 复用同一 GSV 过滤定义；在一组聚合内返回金额、去重订单/买家数，以及未知身份/订单金额。分母覆盖不足时不输出误导性的均值，不用新老客人数相加替代完整买家数。
3. 明确零额订单、负金额/异常退款和未知键的处理，先用多行订单、未知用户、全退/部分退、跨渠道、零分母等合成夹具验证。源字段无法支持的能力留不可用。
4. 真实阶段限定已确认日期与权限，优先已有服务；归档库仍不复制、迁移、回填或改写。只读连接、锁及资源预算须另核验。合成适配器不放宽大小限制去接131GiB归档。
5. 当前无会员事件/退款事件表；先补来源证明和最小必要上游明细，不能只增加数据库空列就宣布接通。

后续核对只针对实质差异。当前看板 GSV 优先级、AUS/AOV分母、会员溢价比较对象等已经确认的原则不重复问。数据来源、能力上线、真实业务验收分别记状态。
