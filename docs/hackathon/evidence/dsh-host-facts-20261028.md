## 读取合同

宿主通过现有 `POST /api/v1/analytics/page-result-access/read` 请求 `mode: facts`。请求沿用页面或预览目标、来源引用与当前身份，不接受客户端选择器、SQL 或分页参数。iframe 原有桥接模式仍为 summary、page、range。

服务端从完整、已授权的 warehouse 投影展开事实。购买包含五个指标；商品包含每个展示名的本期、对比期和同比字段；RFM 保留 rows、same_channel_rows、member_rows、member_same_channel_rows 四组的精确分层键。字段、期间和单位沿用既有投影目录。

响应版本为 `warehouse-facts/v1`，含来源摘要、失效时间、明确选择地址和原始数值。超大整数保持十进制字符串，来源 null 保留为 null。完整响应最多 2000 个事实、512 KiB。身份为空或重复、商品覆盖不足、超限、撤权和过期均拒绝整次请求。旧读取仍限制为 64 KiB。

宿主根据已保存的 binding_manifest 重读事实，不持久化另一份数值或执行模型提供的取值代码。页面内自由 HTML 的叙述和图表仍未核验；`BOUND_VERIFIED` 继续只表示来源核验。

## 当前证据

主仓定向回归为 171 passed、1 warning，覆盖合同、选择器、HTTP、原生来源及既有读写。警告为 Starlette TestClient 的 httpx 弃用提示。15 商品用例返回 705 个事实，保留最后一个商品的最后一个同比字段。RFM 四组同名分层用不同数值验证，不相互覆盖。HTTP 用例覆盖文案编辑后保存重开、来源变更、失效和撤权。

Workbench iframe 模式负测修复前出现 `event != error`，增加原有模式白名单后 7 项通过。Workbench 当前定向回归 108 项通过，覆盖宿主事实面板、原生预览桥和历史工具卡。Host 与 Client 完整类型检查通过，当前构建及构建产物 5 项测试通过，离线合同生成检查通过。构建产物测试首次因未传 B0_BUILD_TOOLS 未运行，补齐固定工具链参数后通过，未改产品代码绕过检查。

Chrome 156.0.8078.48 使用实际 CockpitWorkspace/CockpitPageEditor 和合成 native transport 完成对抗验收。四组 RFM、商品三期间和末项、大整数与 null 均保留；iframe 访问宿主 DOM 被拒绝，CSS 和伪造消息不能改宿主事实；确认保存及重新打开会使用正确目标重新读取；取消和迟到响应不复活旧值，单来源失败独立展示，TTL 到期清空事实。浏览器未捕获运行异常。本机界面另通过“确认保存页面”按钮核验已保存状态，仍为合成接口，不能声称真实数据已落盘。

历史工具卡重挂载不再自动接收页面包。无等待中的生成请求时，需要点击“接收到驾驶舱”；等待中的生成仍自动收到匹配回执。失败可以重试，离开后完成不再导航。未保存候选的离开提醒继续保留。
