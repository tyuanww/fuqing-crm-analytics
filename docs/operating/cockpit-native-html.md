# 从对话生成可编辑 HTML 驾驶舱

0.16.0.2（[#50](https://github.com/tyuanww/fuqing-crm-analytics/pull/50)）是公开 main 的功能基线；现役 6677 当前加载 0.18.0.0 候选插件和 DSH 0.1.7-rc.1。对话自己写 HTML，工作台负责收件、预览和确认保存。工作台不把查出的数字拼成页面，也不把 CRM 快照自动组进这一页。

已经在驾驶舱里的产物，用「用 AI 改」修改，见 [用原生 AI 修改产物](cockpit-ai-edit.md)。本文只写新生成一页。

## 你要做的

1. 在当前对话里把诊断做完。需要生意数字时，让对话调用已经连接的 CRM 看板工具。知识库不提供这些数字。
2. 用下面任一方式开始，保存后的结果相同。
   - 点输入区的「生成驾驶舱」。
   - 在对话里说「生成 HTML」或「搞定 HTML」。
3. 对话写好页面后，调用 `free_html_page_generate`，交出 `html`、`css`、`js`、`resources`、`node_map`。这个工具不查数、不写本地文件、也不保存。
4. 工作台先把页面登记到插件自己的产物收件箱，状态为 `RECEIVED`/`PREVIEWABLE`，标题默认是「本场对话驾驶舱」。候选不会直接写入正式页面库。
5. 工具卡片只显示非阻塞提示和两个入口：
   - 点「打开驾驶舱」后，在收件箱预览、确认保存或丢弃；确认后才创建正式页面和版本。
   - 点「在 DSH 中查看」才打开当前会话的原生 HTML 产物；不会自动抢走对话焦点或强制打开侧边栏。

## 点按钮

工作台向当前这场对话发出一条带 `page-gen-` 标识的请求，并等待这次交付。标识必须原样填进工具的 `request_id`。

成功后，输入区显示「页面已生成，已登记到驾驶舱产物收件箱；确认后才保存正式页面。」

这场对话没有接受请求时，会立刻停住，不再空等页面。输入区显示「未能提交生成请求；请在当前原生对话输入“生成驾驶舱”。」先在该对话选好可用模型，再点一次。

## 只在对话里说

没有人预先等一个标识。模型仍要调用 `free_html_page_generate`。消息里没有 `page-gen-` 标识时，模型自己填一个以 `page-gen-` 开头的新标识。

回执里带有这场对话的 `session_id`，工作台才把页面登记进这场对话的收件箱。没有 `session_id` 就不登记。保存失败时，候选仍保留在收件箱，可按同一回执重试；页面不会进入正式页面库。

## 不会自动发生的事

- CRM 里已有的分析快照不会被自动拼进这个 HTML。保存分析、把分析加入驾驶舱，仍在「CRM 分析」里由你确认。
- 不要改成 BoardSpec，也不要用写本地文件代替这个工具。
- 件数、SKU、退款明细、成交时会员身份在数仓还没有对应字段时，工具说明不可用，不编数字。
- 右侧栏只预览。改文字和选区在驾驶舱里做。页面被压缩后仍可点选数字；同一标签里的第 n 个节点也可以点选。

## 产物收件箱接口

插件服务前缀为 `/api/v1/analytics/cockpit-artifacts`。`POST /` 登记候选，`GET /` 列表，`GET /{artifact_id}` 读取候选；`POST /{artifact_id}/confirm` 确认保存，`POST /{artifact_id}/dismiss` 丢弃。状态固定为 `RECEIVED`、`PREVIEWABLE`、`SAVED`、`DISMISSED`，服务端按来源、会话/请求和内容哈希幂等去重。候选包会留在收件箱，确认接口才关联正式 `page_id`。

没有实时工作区事件时，驾驶舱打开或自由 HTML 生成完成后会按会话每 2 秒扫描一次，最多 20 秒，并保留手动刷新；扫描只接受工作区内的安全相对路径。
