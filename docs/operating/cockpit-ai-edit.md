# 用原生 AI 修改产物

> **2026-09-21 本地候选补充**：`codex/cockpit-inline-edit` 已增加脚本卡片文案、页内 AI 要求和原生右栏统一预览，尚未加载现役。新流程、稳定身份与旧标签兼容限制见[实现说明](../hackathon/COCKPIT-PRESENTATION-2026-09-21.md)。下文“动态区域只读”和“模型完成后回驾驶舱”描述 0.13.0.0 现役流程；不代表本地候选的新行为。

本功能 **0.13.0.0 已由 [#36](https://github.com/tyuanww/fuqing-crm-analytics/pull/36) 合入 `7575d07` 并加载现役 6677**，PR 与该 main CI 均通过；验收边界见[当前 UI / UX 报告](../hackathon/COCKPIT-UI-UX-2026-09-20.md)，早期 AI 接线证据见[历史报告](../hackathon/COCKPIT-AI-EDIT-2026-09-20.md)。沿用[本地文档服务](cockpit-office-local.md)与原生模型设置，不另接 provider 或复制凭据。

1. 在驾驶舱选择产物，先保存或放弃手动编辑，点击“用 AI 改”。历史会话文件先保存独立副本。
2. 原生对话会打开本次产物修改任务。描述需要修改的内容；模型完成后回驾驶舱。
3. 点击“收取修改”，比较原版本和修改后预览。Office/表格/PDF预览是只读；CSV首次打开需要确认编码/分隔符。
4. 点击“确认保存新版本”。保存回执未知时保留页面，用同一按钮重试核对；不要重建任务代替核对。

候选会保留，刷新后可以继续。原文件有新版本时，旧候选不会覆盖它，应放弃旧任务、基于新版本重做。若需继续修改已经收取的候选，先放弃该候选，再基于正式版本创建新任务；已经收取的内容不会被模型后续写入替换。

页面候选超过底层预览的30分钟有效期后，确认时会基于同一份固化候选续建预览并再次检查版本；不会重新读取模型的工作文件。页面数据权限撤销后，任务列表和重复打开请求也按当前权限过滤或拒绝。

“放弃本次修改”只关闭候选；若原生对话还在运行，需要在对话里停止。带业务绑定的 HTML 只允许整页 AI 任务修改 CSS，不开放普通选区修改；扫描 PDF 没有 OCR。原生 `minimax-cn/MiniMax-M3` 已完成五个合成案例的真实模型最终评估：3 项修改交付并确认新版本、2 项越界请求拒绝。任务说明与评估判据修复后的五项复跑及人工答复核对通过，**主线集成后完整 backend/B0、末尾提示文案 B0 冻结复验及公开工作树正常 pre-push 通过**；reload 后真实 DSH 宿主的驾驶舱与新入口可见性检查通过；完整编辑旅程及真实用户 HTML UAT 尚未验收，reload 检查未再次调用模型。证据与计费信息见[当前 UI / UX 报告](../hackathon/COCKPIT-UI-UX-2026-09-20.md)。

## HTML 选区编辑与展示

在原始 HTML 预览中先点击“保存为可编辑副本”并确认，然后进入“编辑”。普通静态 HTML 无需预先带 `data-shine-node`：点选文字可直接替换，也可切换到上级板块并点击“用 AI 修改此选区”。绑定内容、动态区域或无法可靠解析的结构保持只读。外部资源和 module/defer 脚本等原有导入限制仍在；这些文件应提供可独立运行的 HTML 构建产物。

画布点选、下拉列表和 AI 选区入口共用预览内核验过的可编辑范围。脚本在加载后改写内容时，该区域也会退出可编辑状态；已有文本草稿保留，暂不能提交。暂停预览时同样不能修改选区。SVG/MathML 本身保持只读，其前后的静态文字仍可编辑；文本输入保留原有首尾空白。

选区任务以源 HTML 的 SHA-256、Unicode 字符起止位置及原版本持久化。服务端核对完整静态元素边界；AI 只能修改范围内的 HTML 和内联样式，范围外 HTML 以及共享 CSS、JS、资源和映射必须保持不变。越界候选收取失败，原版本不变。本入口没有 CSS/JS/资源选区或扩权操作；模型应简短解释限制、明确未生成候选后停止，不能虚构操作入口。需要整页修改时，先处理已有任务，再使用页头的“用 AI 改”。

候选必须保留选区的单一根元素及标签类型，并符合原父级上下文的静态 HTML 结构。例如选中 `<span>` 后不能把它换成 `<div>`，也不能在段落内插入块级元素、嵌套链接/按钮或构造会被浏览器自动重排的列表。服务端同时检查选区原祖先链和候选片段；仅满足源码前后缀未变仍不足以通过收取。前端源码推导和服务端解析最多支持 **256 层嵌套**，服务端计算包含原祖先链；超限停止解析并拒绝选区，不通过截断 HTML 保存。

带事件处理、`srcdoc` 或可执行 URL 的区域保持只读。协议判断会先解码 HTML 实体并归一化空白/控制字符，拦截 `javascript:`、`vbscript:`；导航属性中的 `data:` / `blob:` 也不能作为静态选区内容。运行时同时核验节点、子树与祖先，动态链接不会借上级选区或内部文字绕过限制；不受影响的静态兄弟文字仍可编辑。普通 HTTP(S)、相对链接及锚点不因本规则被禁止，静态图片的 data/blob 来源仍遵守原有导入与预览 CSP 限制。

产物列表只显示标题；路径、来源及版本通过悬停查看，搜索仍匹配来源。拖动“产物”标题栏可将整个面板拖出左侧，在驾驶舱范围内自由移动；浮动面板右下角支持双向缩放，“停靠”恢复左侧。位置与尺寸随账号保存，窄屏自动回到可用的整栏布局。同类产物左侧手柄支持拖动排序和上下方向键；保存排序时保留手柄焦点，待保存完成后可继续调整。侧栏分隔条可拖动、左右方向键调宽，双击复位。顺序、宽度和回收站均按当前身份保存。删除按钮移入回收站，可恢复；不会删除历史原文件和版本，也不自动停止原生 AI 对话。取消删除后焦点回到触发按钮；删除或恢复后若该按钮已离开列表，焦点回到产物标题抓手。

点击“全屏展示”仅保留预览，Esc 或右上角按钮退出。常规模式标题条保持一行，长标题省略并可悬停查看全文，版本徽标不被挤压；已保存/放弃的 AI 任务默认折叠，处理中和待确认任务保留操作入口。

新请求失败会在折叠状态之外直接显示错误；已保存后刷新失败仍明确显示新版本已保存。重新请求成功后清除错误，不必展开旧任务查找失败原因。

产物组织使用 `GET/PATCH /api/v1/analytics/cockpit-files/preferences`，PATCH 每次只接受 `remove`、`restore`、`order`、`rail_width`、`rail_layout` 中一个字段。存储是现有文件 SQLite 下的独立 `cockpit_preferences` 表；不改变文件和版本表，旧版本忽略该表即可读取原产物。

## 本地接入合同

所有普通请求使用现有产物服务Bearer身份及dashboard读/写权限；页面任务再核验页面数据权限。固定前缀 `/api/v1/analytics/cockpit-ai`，请求模型纳入本地FastAPI OpenAPI；客户端类型在 `cockpit-ai-client.d.mts`。

| 方法/路径 | 内容 |
|---|---|
| GET `/?offset=0` | 当前用户仍有权访问的未完成任务；每页100条，按`next_offset`继续，null表示结束 |
| POST `/` | `{id: ai_UUIDv4, target_kind: file或page, target_id, base_version, selection?}`；selection 为 `{start,end,html_hash}`，仅 page 支持；稳定id重试返回同一任务 |
| GET `/{id}` | 任务状态、基线、原生会话身份及专用目录；不是正式保存回执 |
| POST `/{id}/collect` | 固化固定候选路径；不接收任意路径或URL |
| GET `/{id}/comparison` | 有界文本差异与原件/候选大小、hash |
| GET `/{id}/content?variant=source或candidate` | 受鉴权的二进制内容；HTML仅在沙箱展示 |
| GET `/{id}/viewer?variant=...` | 签名的ONLYOFFICE只读配置；签名内容URL仅限本任务和变体 |
| POST `/{id}/confirm` | `{candidate_hash}`；CAS+幂等确认，返回SAVED及saved_version |
| POST `/{id}/cancel` | 关闭候选；不删除原件或停止模型 |

状态为 WAITING → READY → SAVED，或 CANCELLED。目录位于显式page_state_dir的 `files/ai-workspaces/ai_UUID`，只含任务说明、输入副本和模型工作文件；不保存HTTP令牌。文件服务与DSH须运行在同一本机，才可直接打开这个目录。

文档预览使用 ONLYOFFICE 官方 [`mode: view`](https://api.onlyoffice.com/docs/docs-api/get-started/how-it-works/viewing/) 和 [`permissions.edit: false`](https://api.onlyoffice.com/docs/docs-api/usage-api/config/document/permissions/)，不把编辑器的AI菜单当成原生AI接线。
