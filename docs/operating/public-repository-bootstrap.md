旧文档原样导入会被当作全量新增。`.githooks/public-snapshot-docs.sha256` 固定记录原样历史文档的指纹，检查器同时校验清单指纹和暂存区/提交内容；任一变化恢复普通检查。这个识别仅说明内容来自旧快照，不宣称历史问题已解决或历史验收已重跑。旧仓库提交记录留本地，新仓库不伪造旧 Git 历史。
