## Runtime peer closure

外部 web plugin 通过 `dsh.client.inject` 使用的 peer alias 必须存在于固定上游的 canonical peer root。当前显式闭包为：

```text
dsh-api-session-controller
dsh-api-workspace-files
dsh-client-connection
dsh-client-ui-conversation
dsh-client-ui-layout
dsh-client-ui-renderer
dsh-client-ui-sidebar
dsh-client-ui-sidebar-right
dsh-client-ui-theme
dsh-client-ui-tool
dsh-client-ui-workspace
dsh-tools
```

`runtime-bundle.mjs` 会先检查这些 alias 是否齐全，再物化 peer-only workspace package。缺一项就以 `RUNTIME_EXTERNAL_WEB_PLUGIN_PEER_MISSING` 失败；不会生成一个表面安装成功、启动时才 `ERR_MODULE_NOT_FOUND` 的 bundle。`owner-profile-bridge.mjs` 只在 top-level alias 或 `node_modules/.pnpm/node_modules` canonical root 找到已验证 `package.json` 时建立 link。

## 检查字段

| 字段 | 含义 |
|---|---|
| `runtime_bundle_provenance` | runtime provenance schema 和摘要检查；必须为 `PASS` |
| `native_and_business_boot` | DSH 原生壳与选定插件能否启动 |
| `login_loopback_callback` | 本地登录链路；`PASS_WAITING_BROWSER` 只能表示等待浏览器回读 |
| `settings_rpc` / `account_state_rpc` | 原生 Settings 与账户状态 RPC |
| `browser_plugin_page` | 浏览器插件页可读 |
| `plugin_market_discover_tab` | 插件市场 Discover tab 可读 |
| `console_logs` | 浏览器控制台采集结果；`EMPTY` 才表示本次采集没有日志 |
| `appledouble_locale_files` | 生成 bundle 中的 AppleDouble 文件数量，必须为 `0` |
| `peer_alias_missing_negative_test` | 缺 alias 是否 fail-closed |
| `release_ready` | 是否满足正式发布门禁；候选本地 PASS 不会自动置为 true |

## 状态值

```text
PASS                         单项检查已在指定范围通过
PASS_WAITING_BROWSER         HTTP 登录边界通过，等待 headed browser 回读
BLOCKED_MISSING_ARTIFACT     依赖包或 index 没有在可验证归档输入中
HELD_PENDING_IM_ARTIFACT     production switch 因 IM 缺口保持暂停
NOT_RUN                      尚未执行，不可写成 PASS
```

当前 v4 的 IM 字段为 `BLOCKED_MISSING_ARTIFACT`，来源为 `NOT_FOUND_IN_ARCHIVED_PLUGIN_INPUTS`，因此 `release_ready=false`，线上 `current` 不变。
